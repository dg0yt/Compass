# Orienteering Compass

### Simple and beautiful orientieering-style compass for Android

This project is intended to offer a simple orienteering-style compass for Android

</div>

## Features

* Can point to magnetic north as well as true north
* Shows exact degrees and cardinal direction
* Displays sensor status
* Haptic feedback
* Light and Dark theme
* No advertisements
* No trackers
* No annoyance
